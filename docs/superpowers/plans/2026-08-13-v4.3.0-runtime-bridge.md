# V4.3.0 Runtime Bridge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Route authenticated Feishu Gateway turns through Hermes official plugin hooks while preserving the required Hybrid patch bridge, exact native-delivery behavior, legacy compatibility, and fail-open operation.

**Architecture:** `hermes_plugin.py` remains the inert wheel entry point produced by the Integration Core plan; its runtime facade delegates to a new `hermes_plugin_runtime.py`. That module owns ingress/turn state, deterministic identities, a bounded observer worker, and all official-hook normalization. The sidecar remains the sole owner of event validation, card session state, rendering, Feishu delivery, and a new bounded event-id fence; `hook_runtime.py` exposes only narrow Hybrid patch bridge functions and does not regain lifecycle ownership.

**Tech Stack:** Python 3.9+, asyncio, threading, dataclasses, bounded `queue.Queue`, hashlib/canonical JSON, aiohttp, setuptools entry points, pytest and pytest-asyncio.

## Global Constraints

- This plan consumes `hermes_feishu_card.integration.IntegrationMode`, `IntegrationDecision`, and the `hermes-feishu-card` entry point from `docs/superpowers/plans/2026-08-13-v4.3.0-integration-core.md`.
- `register(ctx)` registers only `pre_llm_call`, `post_llm_call`, `on_session_end`, `on_session_reset`, `on_session_finalize`, `pre_tool_call`, `post_tool_call`, `pre_approval_request`, `post_approval_response`, `subagent_start`, and `subagent_stop`; every callback returns `None`.
- Official lifecycle hooks are the only Hybrid producers of turn start, normal turn terminal, stable tool lifecycle, approval observation, and subagent lifecycle. Hybrid patches do not produce duplicates for those events.
- The patch bridge may only bind ingress after Hermes message authorization, submit answer/thinking delta, perform clarify/approval/slash synchronous round trips, and consume a verified terminal disposition.
- `TurnBinding` states are exactly `pending-start`, `card-active`, `native-bypass`, and `terminal`; no transition leaves `native-bypass` or `terminal`.
- `message.started` and successful `message.completed` use bounded synchronous authenticated Sidecar requests. Queueable observer callbacks use a bounded worker and drop HFC work on saturation or worker failure without affecting Hermes.
- `SidecarEvent.schema_version` remains `"1"`; `event_id`, `producer`, and `phase` are optional bounded strings. Accepted producers are exactly `plugin`, `patch`, and `legacy-patch`.
- A repeated event id with the same canonical payload returns the first canonical Sidecar response without reapplying state. A repeated event id with a different canonical payload is rejected before card/session mutation.
- Existing `NativeHandoffStore` remains the durable exact-delivery/ACK authority. The new TTL/LRU event-id fence neither replaces it nor deletes unresolved native-handoff evidence.
- No plugin callback may retain Hermes agent, gateway, source, event, message, conversation history, raw chat id, raw session id, raw tool arguments/results, raw exception body, or complete assistant answer beyond the callback boundary.
- Tool/subagent previews are allowlisted, sanitized, and bounded before enqueueing. Unknown tools show only name and status.
- All callback, transport, registry, and worker failures are fail-open to Hermes. Only explicit Sidecar `{ "ok": true, "applied": true }` may mark a card path active or suppress native text.
- Keep current Legacy `hook_runtime.py` behavior and existing `tests/fixtures/hermes_v2026_4_23` regression coverage intact.
- This runtime plan does not modify installer ownership, manifest v3, capability probing, patch group rendering, recovery, doctor, release version, tag, push, or GitHub Release. Those belong to the later Hybrid patch and installer milestones.

          return self.state is TurnState.CARD_ACTIVE

      def record_started_result(self, result: object) -> TurnState:
          if self.state is not TurnState.PENDING_START:
              return self.state
          if result == {"ok": True, "applied": True}:

          else:

          return self.state

              return False
          self.state = TurnState.TERMINAL
          return True

- [ ] **Step 3: Implement the shared coordinator without a second lifecycle store**

  Add the following public shape to `hermes_feishu_card/hermes_plugin_runtime.py`:

  ```python
  @dataclass(frozen=True)
  class ObserverEvent:
      sequence: int
      producer: str
      payload: dict[str, object]


  class TurnEventCoordinator:
      def __init__(self, turn_id: str, *, max_pending: int = 64,
                   deliver: Callable[[ObserverEvent], None] | None = None,
                   start_worker: bool = True) -> None:
          self.turn_id = turn_id
          self._next = 0
          self._barrier: int | None = None
          self._closed = False
          self._lock = threading.Lock()
          self._queue: queue.Queue[ObserverEvent] = queue.Queue(maxsize=max_pending)
          self._deliver = deliver or (lambda item: None)

      def next_sequence(self, producer: str) -> int:
          if producer not in {"plugin", "patch", "legacy-patch"}:
              raise ValueError("unknown producer")
          with self._lock:
              value, self._next = self._next, self._next + 1
              return value

      def close_terminal_barrier(self) -> int:
          with self._lock:
              self._barrier = self._next - 1
              return self._barrier

      def next_terminal_sequence(self) -> int:
          with self._lock:
              if self._barrier is None:
                  raise ValueError("terminal barrier is not closed")
              value, self._next = self._next, self._next + 1
              self._closed = True
              return value

      def event_id(self, kind: str, *, item_id: str = "", phase: str = "") -> str:
          if kind in {"started", "completed", "failed"}:
              return f"turn:{self.turn_id}:{kind}"
          if kind not in {"tool", "approval", "subagent"} or not item_id:
              raise ValueError("invalid event identity")
          if phase not in {"started", "terminal"}:
              raise ValueError("invalid event phase")
          return f"{kind}:{self.turn_id}:{item_id}:{phase}"

      def submit_observer(self, payload: dict[str, object], *, producer: str) -> bool:
          with self._lock:
              if self._closed or self._barrier is not None:
                  return False
              if producer not in {"plugin", "patch", "legacy-patch"}:
                  raise ValueError("unknown producer")
              sequence, self._next = self._next, self._next + 1
              event = ObserverEvent(sequence, producer, dict(payload, sequence=sequence))
              try:
                  self._queue.put_nowait(event)
              except queue.Full:
                  return False
              return True

      def drain_before_terminal(self, timeout_seconds: float) -> None:
          deadline = time.monotonic() + max(0.0, timeout_seconds)
          while self._queue.unfinished_tasks and time.monotonic() < deadline:
              time.sleep(0.001)

      def close(self) -> None:
          with self._lock:
              self._closed = True
 ```

  Start one daemon worker only when `start_worker is True`; it repeatedly `get()`s an `ObserverEvent`, invokes `_deliver(event)`, catches every delivery exception, and always invokes `task_done()` in `finally`. Use one non-reentrant `threading.Lock` to allocate sequence, close the barrier, and reject post-barrier submissions; `submit_observer()` must allocate directly while holding that lock and must not call `next_sequence()` while holding it. Allocate the sequence before queue insertion. `drain_before_terminal()` waits only until the bounded timeout, then closes queue admission and does not wait indefinitely. `close()` makes late callbacks return `False`; it never blocks a Hermes callback.

  Generate ids exactly with these templates: `turn:{turn_id}:started`, `tool:{turn_id}:{item_id}:{phase}`, `approval:{turn_id}:{item_id}:{phase}`, `subagent:{turn_id}:{item_id}:{phase}`, `turn:{turn_id}:completed`, and `turn:{turn_id}:failed`. Reject unknown kind, missing `item_id`, invalid phase, blank turn id, and producer other than `plugin`, `patch`, or `legacy-patch` with `ValueError` at construction/normalization boundaries; callbacks catch those errors and return `None`.
