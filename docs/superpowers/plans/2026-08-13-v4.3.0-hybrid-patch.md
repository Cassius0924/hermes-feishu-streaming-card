# V4.3.0 Hybrid Patch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在已完成 Integration Core 和 Runtime Bridge 的前提下，将 HFC 的 Hermes source patch 收敛为 capability-selected、严格可检测/可移除的 Hybrid group 集合，同时保持旧 Hermes 的 Legacy patch 字节与行为兼容。

**Architecture:** 本计划只实现总规格的 Task 3（Hybrid patch），不新建 integration selector、official plugin runtime、manifest/plugin-config transaction、doctor/status 或发布文档。`patcher.py` 使用前置 Integration Core 提供的 mode/decision 类型，将每个 source patch 编成严格的 descriptor；v0.20 fixture 提供真实的 gateway/run、cron、Base anchor contract；patch renderer 调用 Runtime Bridge 的既有 ingress、delta、approval-wait 和 terminal-disposition 接口，而不是重新生产官方 lifecycle 事件。

**Tech Stack:** Python 3.9–3.12、`ast`、pytest、Hermes Gateway source fixtures、前置 `hermes_feishu_card.integration`、前置 `hermes_feishu_card.hook_runtime` 薄桥、现有 HFC patcher/Base exact-delivery helpers。

## Global Constraints

- **前置依赖已经完成且必须直接消费：** Integration Core 已提供 `IntegrationMode`、`IntegrationDecision`、`PatchCapabilities` 和 mode selector；Runtime Bridge 的唯一公开 patch bridge 位于 `hermes_feishu_card.hook_runtime`，提供 `bind_ingress_from_hermes_locals(local_vars) -> bool`、`emit_delta_from_hermes_locals_threadsafe(local_vars, event_name) -> bool`、`wait_for_approval_choice_from_hermes_locals(local_vars, approval_data)`、`wait_for_clarify_response_from_hermes_locals(local_vars, interaction_id, question, choices, multi_select)`、`wait_for_slash_confirm_from_hermes_locals(local_vars, command, title, message, interaction_id)`、`consume_terminal_disposition_from_hermes_locals(local_vars) -> dict[str, Any] | None`。patched Hermes source 只能 import/call 这些 `hook_runtime` 薄桥；薄桥内部才委托 coordinator。
- 本计划不得新建或修改 integration selector、官方 plugin callback/registry、manifest v3/plugin config、CLI doctor/status、release 文档或版本号；它们属于相邻总计划任务。
- `apply_patch(content, strategy="legacy_gateway_run", *, integration_mode="legacy-patch")` 必须保持默认 Legacy 行为；对相同 source，默认调用与显式 `legacy-patch` 输出逐字节相同。
- `remove_patch(content)` 只能根据严格验证的 marker body/位置反推当前 groups；不得信任外部 mode 或 manifest；unknown、duplicate、half、reversed、misplaced 或 user-edited marker 必须在 mutation 前 `ValueError`。
- Hybrid source patch 只能保留：`ingress_binding`、`terminal_disposition`、`answer_delta`、`thinking_delta`、`clarify_round_trip`、`approval_round_trip`、`status_notice`、`slash_confirm`、`command_card_startup`、`command_card_adapter`、`native_redelivery`、`platform_notice`、`hfc_command`、`cron_delivery`、`exact_base_no_text`、`exact_base_final_delivery`。
- Hybrid source patch **不得**含有 started、ordinary success/failed terminal、queued terminal、stable/progress tool lifecycle、approval observer 或 subagent lifecycle producer marker；这些事件由前置 Runtime Bridge 的 Hermes official hooks 唯一生产。
- Hybrid 重渲染必须由 verified original 进行：`remove_patch(verified_original)` 验证为 clean 后才调用 `apply_patch(verified_original, strategy=strategy, integration_mode=target_mode)`；不得在旧 Legacy 或 Hybrid marker 上叠加新模式。
- Base exact delivery 的 media/filter/ledger/send/ACK 顺序保持现有 strict AST contract；v0.20 只接受 awaited `asyncio.to_thread` ledger calls，未 await 或非精确 wrapper 均拒绝。
- patch runtime 调用须 fail-open；无 active Runtime Bridge turn、bridge exception、unknown terminal disposition 或不可验证 ingress 时不 suppress、不发送第二个 event，并让 Hermes 原有流程继续。
- 每项先 RED 后 GREEN；每项结束运行 listed focused command 和 `git diff --check`，然后创建单一目的 commit。

```python
@dataclass(frozen=True)
class PatchGroup:
    name: str
    target: str
    begin_marker: str
    end_marker: str
    apply: Callable[[str, str], str]
    remove: Callable[[str], str]
    verify: Callable[[str], bool]


def apply_patch(
    content: str,
    strategy: str = "legacy_gateway_run",
    *,
    integration_mode: str = "legacy-patch",
) -> str:
    mode = IntegrationMode(integration_mode)
    requested = _run_groups_for_mode(mode, strategy)
    present = detect_patch_groups(content)
    if present:
        content = remove_patch(content)
    for group in requested:
        content = group.apply(content, strategy)
    actual = detect_patch_groups(content)
    expected = frozenset(group.name for group in requested)
    if actual != expected:
        raise ValueError("rendered patch groups do not match requested mode")
    return content


def detect_patch_groups(content: str) -> frozenset[str]:
    found = {group.name for group in _ALL_PATCH_GROUPS if group.verify(content)}
    _reject_all_unrecognized_hfc_marker_lines(content, found)
    return frozenset(found)


def remove_patch(content: str) -> str:
    groups = detect_patch_groups(content)
    for group in reversed(_ordered_groups(groups)):
        content = group.remove(content)
    if detect_patch_groups(content):
        raise ValueError("owned patch group remains after removal")
    return content
```

```python
def rerender_patch_from_verified_original(
    original: str,
    *,
    strategy: str,
    decision: IntegrationDecision,
) -> str:
    if detect_patch_groups(original):
        raise ValueError("verified original contains HFC patch groups")
    _reject_all_unrecognized_hfc_marker_lines(original, frozenset())
    target_mode = decision.mode.value
    requested_groups = expected_run_groups(decision)
    rendered = apply_patch(
        original,
        strategy=strategy,
        integration_mode=target_mode,
    )
    if remove_patch(rendered) != original:
        raise ValueError("target mode render is not reversible to verified original")
    if detect_patch_groups(rendered) != requested_groups:
        raise ValueError("target mode group set differs from renderer contract")
    return rendered
```

Define `expected_run_groups(decision: IntegrationDecision) -> frozenset[str]` as `decision.required_patch_groups.intersection(ALL_RUN_PATCH_GROUPS)`. `decision_for_mode("legacy-patch")` returns Integration Core’s Legacy decision, `decision_for_mode("hybrid")` returns its Hybrid decision, and `decision_for_mode("native-hooks")` returns its full-native decision with an empty required patch group set. Reject a decision whose mode is unknown, whose group set includes an unrecognized group, or whose group set contradicts the mode contract. Reject mixed marker families and any marker line hidden in a string/comment that matches an HFC marker token. Do not migrate by applying a target mode to installed content; tests must prove the function receives a clean verified original.
